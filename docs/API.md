# YourContent HTTP API

Generated by `python3 -m medialab openapi --md` from the live route table; the machine-readable version is `docs/openapi.json` (and `GET /api/openapi.json` on a running app).

- Every POST needs the header `X-Media-Lab: 1` and a JSON body (except `/mcp`, and `/api/upload`, which takes the raw file).
- Credentials: `Authorization: Bearer <owner token or mla_ agent token>`, or the page's session cookie, whenever the app has a token. Agent tokens cannot delete or manage access. Without a token none is asked for, and every client that can reach the address has the owner's full access, delete included.
- `GET /api/config` says which applies: `token_required` (bool), `listens` (the address the port is reachable on; `0.0.0.0` = every address of the machine) and `loopback_only` (only this computer can connect). Read-only.
- Errors are `{"error": "a plain sentence"}` with a 4xx/5xx status; a stale `rev` is 409 with the current record.
- Files are references `{root, name}`, served at `/m/<root>/<name>`.

| method | path | what it does |
|---|---|---|
| GET | `/api/agents` | Agent tokens (without secrets) and the setup-prompt presets (owner only). |
| POST | `/api/agents` | Make an agent token and its setup prompt; the token is shown once (owner only). |
| POST | `/api/agents/{p1}/revoke` | Revoke an agent token (owner only). |
| POST | `/api/animate` | Start a clip job that animates a picture (3 or 5 seconds). |
| GET | `/api/brandkits` | The owner's brand kits (colours, fonts, logo, voice). |
| POST | `/api/brandkits` | Make a brand kit (name, colours, fonts, logo ref, handle, voice, default styles). |
| POST | `/api/brandkits/{p1}` | Replace a brand kit. |
| POST | `/api/brandkits/{p1}/delete` | Delete a brand kit (owner only). |
| GET | `/api/calendar` | Content calendar entries between two dates (YYYY-MM-DD). |
| POST | `/api/calendar` | Add a calendar entry. Put finished work on it with status 'ready' and the file as asset. |
| GET | `/api/calendar.ics` | The calendar as an iCalendar file (from, to optional). |
| GET | `/api/calendar/feed` | The private subscribe link for calendar apps (owner only). |
| POST | `/api/calendar/feed/rotate` | Replace the subscribe link; the old one stops working (owner only). |
| GET | `/api/calendar/feed/{p1}.ics` | The calendar feed for calendar apps; the secret in the path is the credential. |
| POST | `/api/calendar/{p1}` | Change a calendar entry: send its rev and only the fields that change. |
| POST | `/api/calendar/{p1}/delete` | Delete a calendar entry (owner only). |
| GET | `/api/config` | Limits, presets, model choices and licence rows for the page, and how the app is reached: listens (address), loopback_only, token_required (no credential needed). |
| GET | `/api/craft` | Recent craft jobs and the recipe service's state. |
| POST | `/api/craft` | Start a photo/video recipe job; params per recipe are listed by craft_recipes. |
| GET | `/api/craft/recipes` | A craft job's state and outputs. |
| GET | `/api/craft/{p1}` | A craft job's state and outputs. |
| POST | `/api/delete` | Delete a file YourContent made or adopted, for good (owner only). |
| POST | `/api/extend` | Start a job that adds 3 or 5 seconds to the end of a clip. |
| POST | `/api/generate` | Start a picture job from a prompt (optionally up to 6 reference pictures). |
| POST | `/api/google/bootstrap` | Create or repair the workspace folder, subfolders and Content Plan Sheet. |
| GET | `/api/google/callback` | Google's redirect back after consent (single-use state). |
| POST | `/api/google/connect` | Start Google sign-in (drive.file access); returns the consent URL (owner only). |
| POST | `/api/google/disconnect` | Revoke Google access and forget the tokens; Drive files stay (owner only). |
| GET | `/api/google/inbox` | Files in the workspace's Inbox folder that YourContent can see. |
| POST | `/api/google/inbox/import` | Copy an Inbox file into YourContent's uploads. |
| POST | `/api/google/manual` | Save pasted folder and Sheet ids as the workspace (links only) (owner only). |
| GET | `/api/google/status` | Whether Google Drive is connected, and the workspace folder and Sheet links. |
| POST | `/api/google/sync` | Sync the calendar with the Content Plan Sheet both ways (the side that changed wins). |
| POST | `/api/google/upload` | Copy a finished file to the Google workspace (folder: rendered or exports). |
| GET | `/api/health` | Which features work right now (models present, ComfyUI up) and why not. |
| GET | `/api/info/{p1}/{p2}` | One file's details and licence record (root, name). |
| GET | `/api/jobs` | All jobs, newest first. |
| GET | `/api/jobs/{p1}` | A job's state and result. wait_seconds (up to 110) waits until it finishes. |
| POST | `/api/jobs/{p1}/cancel` | Cancel a queued or running job. |
| POST | `/api/login` | Exchange the owner token for a session cookie. |
| POST | `/api/logout` | Drop the session cookie. |
| POST | `/api/music` | Start a music job from style tags (and optional lyrics; '[Instrumental]' for none). |
| GET | `/api/openapi.json` | This document. |
| GET | `/api/posts/health` | Whether the post renderer is up, and why not. |
| POST | `/api/posts/render` | Render a styled post image from a brand kit, a style (list_styles), text and optional pictures. Saved to the library with a licence label; the file is item.ref in the reply. |
| GET | `/api/projects` | Cuts (timeline projects). |
| POST | `/api/projects` | Make an empty cut. |
| GET | `/api/projects/{p1}` | A cut with its items, music and resolved timing. |
| POST | `/api/projects/{p1}` | Replace a cut (send the rev you read; a stale rev is refused). |
| POST | `/api/projects/{p1}/delete` | Delete a cut (owner only). |
| POST | `/api/projects/{p1}/export` | Start the final MP4 export of a cut. |
| POST | `/api/projects/{p1}/preview` | Start a low-resolution preview render of a cut (send its rev). |
| GET | `/api/recent` | Recent pictures, clips, music and exports, newest first, with licence labels. |
| GET | `/api/styles` | Post styles available for render_post. |
| GET | `/api/tracks` | Music tracks usable in a cut. |
| POST | `/api/upload` | Upload a picture, video or audio file: raw body, Content-Type, X-Filename header. |
| POST | `/mcp` | MCP over Streamable HTTP (JSON-RPC in, JSON out). |
| GET | `/mcp` | Not used: 405 (this MCP endpoint has no event stream). |
